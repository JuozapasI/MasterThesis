\section{Data Acquisition}

\paragraph{\textbf{scRNAseq datasets}}

We analyzed datasets from four different human tissues: brain, blood, lung, and eye.
All samples, except for two Peripheral Blood Mononuclear Cell (PBMC) datasets,
were generated using the 10x Genomics v3.1 protocol.
The two exceptions were prepared using the inDrops2 protocol (\cite{Juzenas2025}).
All protocols capture 3' ends of RNA molecules and use short-read sequencing.
The datasets are publicly available, with sources and additional details provided in Table \ref{tab:datasets}.

\paragraph{\textbf{Genome and Transcriptomic references}}

The human genome assembly GRCh38 was used in this project, downloaded from the \href{https://ftp.ensembl.org/pub/release-113/fasta/homo_sapiens/dna/}{Ensembl website}.

Four transcriptomic references were analyzed (see Table \ref{tab:references} for details).
To ensure compatibility with the genome FASTA file, chromosome name prefixes ('chr') were removed from references that included them,
as the genome file does not use these prefixes.
This modification was performed using basic Linux command-line tools.
Additionally, for the NCBI reference, chromosome names were converted to Ensembl-style notation using a custom Python script
(e.g., 1, 2, 3 instead of NC\_000001.11, NC\_000002.12, NC\_000003.12, etc.).

For references that do not have 'gene' entries, such entries were added
(entries that span all the components of a particular gene).

\section{Computational Tools and Environment}

All analyses were performed on a high-performance computing (HPC) cluster running a Linux environment.
Software packages and tools were managed using Conda.
The exact Conda environment specifications (YAML file) can be found on \href{https://github.com/JuozapasI/MasterThesis/}{GitHub repository}.
Besides tools managed by conda, also basic command line tools were used (e.g. \textit{awk, wc, grep, sed, uniq, sort} and similar).
The specific functions and parameters used are described in the following sections, where the general analysis pipeline will be explained.

\section{Data processing pipeline}

The pipeline was implemented using GNU Make,
and the full scripts are available on \href{https://github.com/JuozapasI/MasterThesis/}{GitHub}.
Here, only a general description of the workflow and tools used is provided.

The overall structure of the pipeline, which was applied both for extracting intergenic regions and enhancing the transcriptomic reference, is shown in Figure~\ref{fig:pipeline}, with a step-by-step description provided below:

\begin{enumerate}
    \item Map reads using initial transcriptomic reference.
    \item Extract unassigned and uniquely mapped reads.
    \item Separate reads into two categories: intersecting with genes and intergenic.
    \begin{enumerate}
        \item For intersecting:
        \begin{enumerate}
            \item Resolve cases of overlapping genes that also overlap with unassigned reads.
            \item From the second reference onward, add genes to the original transcriptomic reference if they:
            \begin{itemize}
              \item overlap with unassigned reads, and
              \item do not overlap with entries in the original reference.
            \end{itemize}
        \end{enumerate}
        \item For intergenic:
        \begin{enumerate}
            \item Cluster the reads.
            \item Filter out small clusters (custom threshold).
            \item For the first reference only: filter-out AT-rich reads.
            \item For the remaining reads, repeat the process with the next reference.
            \item For the final reference only: assign clusters that start immediately downstream of 3' ends
            of known genes to those genes (by extending gene annotations in the reference).
        \end{enumerate}
    \end{enumerate}
    \item Construct the final transcriptomic reference and remap the original reads to it.
    \item Generate a list of large intergenic clusters (custom threshold).
\end{enumerate}

\paragraph{Mapping and filtering bam files}
Reads were mapped using STARsolo (\cite{Kaminow2021}) from both FASTQ and BAM input files.
The same parameters were used across all samples (see the \href{https://github.com/JuozapasI/MasterThesis/}{GitHub repository}),
except for those related to barcode structure—differences included the number of barcodes, lengths of barcode/UMI sequences, and their positions in the primers.
Unassigned reads were filtered using \textit{awk} by selecting those that:
\begin{enumerate}
  \item had valid barcodes (i.e., barcode length matched the expected value)
  \item were not assigned to any gene (tagged with \texttt{GN:Z:-})
  \item were uniquely mapped (tagged with \texttt{NH:i:1}).
\end{enumerate}

\paragraph{Classifying reads as 'intergenic' or 'intersecting' and read clustering}
Unassigned reads were classified as either 'intersecting' or 'intergenic' based on their overlap with the reference genome,
using the \textit{bedtools intersect} command.
Reads that intersected with genes were categorized as 'intersecting', while those that did not intersect were classified as 'intergenic'.
Intersections were assessed in a strand-specific manner using the \texttt{-s} flag in \textit{bedtools},
meaning that regions on different strands were treated as non-intersecting,
even if they shared overlapping genomic coordinates (see Figure \ref{fig:intergenicIntersecting}).
Intergenic reads were then clustered using \textit{bedtools merge}, again considering strand specificity.

  \caption{Classification of unassigned reads as 'intergenic' or 'intersecting'.
  Reads are classified as intersecting if they overlap with known genes and are on the same strand.

\paragraph{Manipulating transcriptomic references}

The process of resolving overlapping genes and constructing the enhanced transcriptomic reference
was carried out using a custom R scripts, specifically utilizing the \textit{rtracklayer} library.

\section{Intergenic regions}

\paragraph{Extracting intergenic regions}

The intergenic reads were extracted as described in the previous section (i.e., unassigned reads that
do not overlap with any reference used) and clustered using the \textit{bedtools merge} command.
Clusters were filtered based on their size, requiring at least 5 reads per million (CPM),
where CPM represents the normalized read count per million total primary reads in the dataset
(i.e., $1 CPM = 1 \times sample\_size / 1000000$). This filtering was performed using \textit{awk}.

Cluster locations were adjusted using \textit{deeptools} (for coverage calculation)
and a custom Python script to prevent long introns from skewing the width of the intergenic clusters.
To accomplish this, for each intergenic region, the maximum coverage location was identified and extended to include neighboring regions with at least half of the maximum coverage.

The lists from all samples were then merged using the \textit{bedtools merge} function.
This combined list was further filtered to retain only regions detected in at least all samples from one tissue group (e.g., 'eye', 'lung', 'brain', 'PBMC\_10x', or 'PBMC\_indrops').
This filtering allows for the inclusion of tissue-specific regions while removing those that
are not persistent across the same sample type.
Additionally, for each entry, we determined whether it overlaps with predicted genes from the UCSC Gene Prediction Archive (using \textit{bedtools merge})
and calculated the distances to the closest genes (using \textit{bedtools closest}).
Intergenic regions located on the opposite strand of known genes were classified as \textit{antisense},
while those that were not were classified as \textit{isolated} (see Figure \ref{fig:antisenseIsolated} for illustration).

\begin{figure}
  \centering
  \includegraphics[width=\linewidth]{"images/antisenseIsolated.png"}
  \caption{Classification of intergenic regions as antisense or isolated.}
  \label{fig:antisenseIsolated}
\end{figure}

This filtered combined list was then converted into GTF format,
and unassigned reads from each sample were mapped using this combined intergenic annotation.

\paragraph{Analysis of cell-gene matrices}

The matrices produced by STARsolo were filtered to retain cells with a sufficient number of reads
(thresholds selected manually) and genes expressed in at least three cells.
Additionally, cells were filtered based on mitochondrial gene content,
allowing up to 10\% of mitochondrial reads per cell.
Doublets were identified and removed using \textit{scrublet}.

After filtering, the matrices were normalized using the \textit{normalize\_total} function from the \textit{scanpy} package
and log-transformed
(i.e., each entry $x$ was transformed as $x = \log(x+1)$ using the \textit{log1p} function from \textit{scanpy}).

Subsequently, only highly variable genes were retained
(with parameters: \texttt{min\_mean=0.0125}, \texttt{max\_mean=3}, \texttt{min\_disp=0.5}).
For clustering, principal components (PCs) were computed,
and an optimal number was selected manually based on the elbow rule.
In \textit{PBMC\_10x} samples, cells were annotated automatically using CellTypist.
For other samples, annotation was omitted, as it was not the main focus of the project.
Visualizations were generated using UMAP embeddings, also implemented via \textit{scanpy}.

All scripts and additional descriptions are available in the \href{https://github.com/JuozapasI/MasterThesis/}{GitHub repository}.

\paragraph{Correlations}

Spearman's rank correlation between intergenic regions and nearby genes was calculated using a custom Python script.
The formula for Spearman's correlation is:

$$\rho = 1 - \frac{6 \sum d_i^2}{n(n^2 - 1)}$$

where $d_i$ is the difference between the ranks of the corresponding values, and $n$ is the number of observations.

\paragraph{Nanopore data}

ONT data were aligned to the genome using the \textit{minimap2} algorithm and possible transcript structures were inferred using \textit{stringtie} transcript assembler tool.

\section{Enhancing transcriptomic reference}
\label{sec:overlappers}

Three aspects were considered while enhancing transcriptomic reference:
\begin{itemize}
  \item \textbf{Gene overlaps} – some of the genes are overlapping, resulting in unassigned reads from those overlapping regions.
  \item \textbf{3' end extensions} – for certain genes, clusters of reads appear just beyond their annotated 3' ends.
  \textcite{Pool2023} suggested that such reads may be biologically relevant and
  can be included by extending the 3' ends of affected genes.
  \item \textbf{Different annotations} – although most annotations agree on the majority of genes,
  a small fraction are present in some references but absent in others.
  To address this, multiple transcriptomic references were used during the enhancement process.
\end{itemize}

\paragraph{Overlaps}

The criteria for resolving overlapping genes were as follows:
\begin{enumerate}
  \item \textbf{Gene type}: Protein-coding genes were preferred over other types,
  and long non-coding RNAs (lncRNAs) were preferred over the remaining categories (e.g., pseudogenes).
  \item \textbf{Level}: Some references include a 'level' field indicating annotation quality —
  1 for verified, 2 for manually annotated, and 3 for automatically annotated genes.
  Genes with lower scores were given higher priority.
  \item \textbf{Intersection types}: If the 5' end of one gene overlapped with the 3' end of another,
  the 5' end gene was shortened.
\end{enumerate}

Gene types were divided into three classes: protein-coding, long non-coding RNAs, and other.
Each class was assigned a score, as shown in Table \ref{tab:geneTypes}.
The overall priority score was defined as the sum of the gene type score and the annotation level.
A lower priority score indicates a higher-priority gene.

Intersection type (i.e., whether a 3' end is involved) was only considered in cases where the priority score
were equal and the distance between the overlapping genes' 3' ends exceeded 1 kb.
In such cases, lower-priority genes were either shortened or removed entirely,
depending on whether shortening resolved the overlap (see Figure \ref{fig:overlappers} for a graphical illustration).

\paragraph{3' end extensions}

Clusters of unassigned reads (with a size of at least 1 CPM) located within 100 bp downstream of a gene's 3' end
were assumed to originate from that gene.
Consequently, the corresponding gene annotations were extended to include these clusters.

\paragraph{Multiple annotations}

The initial transcriptomic reference (obtained from the 10x Genomics website)
was incrementally enriched with gene entries from GENCODE, RefSeq (NCBI), and LNCipedia annotations.
Specifically, entries from these sources were added if they overlapped with unassigned reads
and did not overlap with genes already present in the current reference.
The enrichment was performed sequentially: first incorporating relevant entries from GENCODE, followed by RefSeq, and finally LNCipedia.
